# Ren'Lua
[English](README.md) | [Русский](README_RU.md) | [Українська](README_UA.md)

**Ren'Lua** — експериментальний рушій візуальних новел, що розробляється на **Lua та LÖVE2D**.

Проєкт розпочався як спосіб вивчення Lua через практичну розробку. Довгострокова мета — створити легкий рушій візуальних новел, натхненний Ren'Py.

Наразі Ren'Lua перебуває на ранній стадії прототипу та ще не готовий до створення й розповсюдження повноцінних візуальних новел.

## Реалізовані можливості

- Відображення діалогів із підтримкою Unicode-шрифтів
- Імена персонажів з індивідуальними кольорами
- Зберігання визначень персонажів окремо від сценаріїв
- Завантаження сценаріїв у вигляді Lua-модулів
- Перемикання реплік клавішею Space
- Автоматичне повернення до першої репліки після останньої
- Вихід із застосунку клавішею Escape
- Просте діалогове вікно, намальоване засобами LÖVE2D

## Технології

- **Мова:** Lua (через LuaJIT)
- **Фреймворк:** LÖVE2D
- **Платформа:** Windows (наразі протестовано лише її)

## Встановлення та запуск

### Вимоги

Встановіть [LÖVE2D](https://love2d.org/).

Окремо встановлювати Lua для запуску проєкту не потрібно.

### Запуск

Клонуйте репозиторій:

```bash
git clone https://github.com/UrrovenGrrunta/RenLua.git
cd RenLua
```

Запустіть проєкт через LÖVE2D.

Приклад для Windows PowerShell:

```powershell
& "C:\Program Files\LOVE\love.exe" .
```

Шлях до `love.exe` може відрізнятися залежно від місця встановлення.

### Керування

| Клавіша | Дія |
|---|---|
| Space | Наступна репліка |
| Escape | Вихід |

## Як це працює

Наразі Ren'Lua використовує таблиці Lua для опису персонажів і сценаріїв.

Персонажі визначаються у файлі `characters.lua`:

```lua
return {
    alice = {
        name = "Alice",
        color = {1, 0.5, 0, 1}
    }
}
```

Діалоги зберігаються окремо:

```lua
return {
    {
        speaker = "alice",
        text = "Hello, world!"
    }
}
```

Основний застосунок завантажує ці модулі за допомогою `require()` та відображає діалоги засобами LÖVE2D.

## Плани на майбутнє

Наведені нижче можливості розглядаються для майбутніх версій, але поки що не реалізовані:

- Фонові зображення та переходи між сценами
- Спрайти персонажів
- Вибір варіантів відповіді та розгалуження сюжету
- Кілька сцен
- Музика та звукові ефекти
- Збереження та завантаження гри
- Власна система сценаріїв
- Додаткові елементи інтерфейсу візуальної новели

Напрям подальшої розробки є експериментальним і може змінюватися.

## Стан розробки

**Ранній прототип — у розробці.**

Ren'Lua — насамперед особистий проєкт для вивчення Lua та експериментів. Функціональність додається поступово, з акцентом на розуміння мови та простоту рушія.
