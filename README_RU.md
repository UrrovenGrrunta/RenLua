# Ren'Lua
[English](README.md) | [Русский](README_RU.md) | [Українська](README_UA.md)

**Ren'Lua** — экспериментальный движок визуальных новелл, разрабатываемый на **Lua и LÖVE2D**.

Проект начался как способ изучить Lua через практическую разработку. Долгосрочная цель — создать лёгкий движок визуальных новелл, вдохновлённый Ren'Py.

Сейчас Ren'Lua находится на ранней стадии прототипа и пока не готов для создания и распространения полноценных визуальных новелл.

## Реализованные возможности

- Отображение диалогов с поддержкой Unicode-шрифтов
- Имена персонажей с индивидуальными цветами
- Хранение персонажей отдельно от сценариев
- Загрузка сценариев в виде Lua-модулей
- Переключение реплик клавишей Space
- Автоматический возврат к первой реплике после последней
- Выход из приложения клавишей Escape
- Простое диалоговое окно, отрисованное средствами LÖVE2D

## Технологии

- **Язык:** Lua (через LuaJIT)
- **Фреймворк:** LÖVE2D
- **Платформа:** Windows (на данный момент протестирована только она)

## Установка и запуск

### Требования

Установите [LÖVE2D](https://love2d.org/).

Отдельная установка Lua для запуска проекта не требуется.

### Запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/YOUR_USERNAME/RenLua.git
cd RenLua
```

Запустите проект через LÖVE2D.

Пример для Windows PowerShell:

```powershell
& "C:\Program Files\LOVE\love.exe" .
```

Путь к `love.exe` может отличаться в зависимости от места установки.

### Управление

| Клавиша | Действие |
|---|---|
| Space | Следующая реплика |
| Escape | Выход |

## Как это работает

На данный момент Ren'Lua использует таблицы Lua для описания персонажей и сценариев.

Персонажи определяются в `characters.lua`:

```lua
return {
    alice = {
        name = "Alice",
        color = {1, 0.5, 0, 1}
    }
}
```

Диалоги хранятся отдельно:

```lua
return {
    {
        speaker = "alice",
        text = "Hello, world!"
    }
}
```

Основное приложение загружает эти модули через `require()` и отображает диалоги с помощью LÖVE2D.

Следующие возможности рассматриваются для будущих версий, но пока не реализованы:

- Фоновые изображения и переходы между сценами

- Выбор вариантов ответа и ветвление сюжета
- Несколько сцен
- Музыка и звуковые эффекты
- Сохранение и загрузка игры
- Собственная система сценариев
- Дополнительные элементы интерфейса визуальной новеллы

Направление дальнейшей разработки экспериментальное и может измениться.
